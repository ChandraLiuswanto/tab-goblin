## Automated blocker and resolved prior blockers

### Current blocker

Ownership generation does not advance for two successful manual ownership transitions. Exact reproduction:

```text
TABGOBLIN_IMAGE=localhost/tabgoblin-runtime:dev npm test -w packages/gateway -- integration
ownership generations: {"beforeTakeover":0,"afterTakeover":0,"afterReclaim":0,"afterReturn":1}
takeoverAdvanced=false, reclaimAdvanced=false, returnAdvanced=true
```

The acceptance test requires each successful takeover, reclaim, and return transition to advance generation. The assertion was not weakened, and production code was not changed. Bead `tabgoblin-server-browser-v7n` remains open.

### Prior blockers confirmed resolved during the completed story

1. `tabgoblin_back` succeeds for meaningful static-page history traversal.
2. `tabgoblin_upload` succeeds across remote CDP, and the receiving fixture verifies exact binary bytes rather than only staging presence.
3. Durable nonzero lifecycle state re-enrolls after plugin reload and gateway restart from the same persisted configuration, without reconfiguration or workspace re-enable.
4. Both compared tab lists are nonempty; reattached tab IDs are unique and have an empty intersection with pre-restart IDs.
5. The exact default parallel `npm test` command passes.

No failure was tolerated or converted into a diagnostic success.
