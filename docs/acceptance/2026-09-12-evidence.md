## Automated blockers resolved

1. Ownership takeover, reclaim, and return now each advance generation and invalidate browser references before publishing new authority. The strict acceptance assertion verifies exact `+1` progression from the current post-lifecycle baseline. Focused tests also verify that takeover waits for the active agent lease to drain and that listener failures at all three transitions fail closed in `needs-attention`.
2. Enrollment binding now requires the request nonce and selects only that exact pending record after cwd, workspace, and lifecycle-generation validation. Admin binding fails closed with `auth_failed` when no exact match exists. A real coordinator+registry regression covers a successfully processed nonce-A record whose response is lost, then proves the retry session binds nonce B rather than nonce A.
3. `tabgoblin_back` succeeds for meaningful static-page history traversal.
4. `tabgoblin_upload` succeeds across remote CDP, and the receiving fixture verifies exact binary bytes rather than only staging presence.
5. Durable nonzero lifecycle state re-enrolls after plugin reload and gateway restart from the same persisted configuration, without reconfiguration or workspace re-enable.
6. Both compared tab lists are nonempty; reattached tab IDs are unique and have an empty intersection with pre-restart IDs.
7. The exact default parallel `npm test` command passes.
8. Browser operation budgets now compose the cold 10-second attachment phase, the requested action timeout, and gateway/transport overhead. A cold 30-second navigation receives 45 seconds at the gateway and 50 seconds at the outer transport; explicit shorter caller deadlines remain authoritative.
9. Runtime stop uses one absolute 30-second deadline across discovery, graceful stop, and removal. Near-deadline completion succeeds, while insufficient remaining graceful-stop time returns non-retryable `timeout_uncertain` and never reports stop success.
10. Stop→ready transitions serialize against mutations, fence agent leases and viewer input, preserve intended manual ownership without stale permission, close stale and late browser attachments even when the CDP URL is reused, and require explicit recovery after uncertain mutation completion.
11. The live fixture supplies deterministic bridge/socket defaults and independently attempts viewer, MCP client, transport, lifecycle, plugin manager, production gateway, runtime container, volume, and filesystem cleanup after partial initialization.
12. Workspace uploads share a 32 MiB protocol limit. Known oversized files, including sparse files, are rejected before temporary-directory creation or runtime staging; descriptor reads stop at the limit plus one probe byte so source growth cannot create an unbounded copy.
13. Confirmed runtime stop removes and recreates only the staging volume without `--force`; the profile volume is preserved. Missing-container stops also fulfill pending staging cleanup, cleanup failure remains pending for retry before launch, and live, foreign, or uncertain containers never trigger staging deletion.

No final verification failure was tolerated or converted into a diagnostic success. Bead `tabgoblin-server-browser-v7n` remains open pending the unavailable operator-only checks.
